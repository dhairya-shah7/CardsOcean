# ElitePay

ElitePay is a premium fintech gift card marketplace monorepo with:

- `apps/web`: Next.js 15 storefront, checkout, and dashboards
- `apps/api`: Express.js API with Prisma and PostgreSQL support

The platform uses dynamic brand configuration, custom card amounts only, and no KYC flows.

## Project layout

- `apps/web/src/app`: route-level pages and layouts
- `apps/web/src/components`: shared UI pieces
- `apps/web/src/lib`: API client and shared front-end types
- `apps/api/src/routes`: feature routes for auth, checkout, cards, orders, and admin
- `apps/api/src/services`: mail, payment, checkout, catalog, and brand helpers
- `apps/api/src/utils`: shared backend utilities, including CSV snapshot writers
- `apps/api/.generated`: runtime CSV and local JSON snapshots generated by the API

## Quick start

1. Install dependencies:

```powershell
npm.cmd install
```

2. Copy env files:

```powershell
Copy-Item apps\\api\\.env.example apps\\api\\.env
Copy-Item apps\\web\\.env.example apps\\web\\.env.local
```

3. Update env values, then run Prisma and seed:

```powershell
npm.cmd --workspace apps/api run prisma:generate
npm.cmd --workspace apps/api run prisma:migrate
npm.cmd seed
```

4. Start both apps:

```powershell
npm.cmd run dev
```

## Default local ports

- Web: `http://localhost:3000`
- API: `http://localhost:4000`

See `API.md` and `DEPLOYMENT.md` for full details.
